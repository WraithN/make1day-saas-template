## ShipKit 生成器：字体清晰度 + 风格可选 + Cloudflare

三个用户诉求（截图反馈"字体发虚"、要可选 SaaS 风格、支持 Cloudflare）已落地：

### 1. 字体/UI 清晰度
- `tailwind.config.ts`：颜色 token 由写死十六进制改为 `rgb(var(--x) / <alpha-value>)`，支持 CSS 变量换肤且保留 `/60` 等透明度修饰符。
- `app/globals.css`：新增 `-moz-osx-font-smoothing: grayscale`、`text-rendering: optimizeLegibility`、`font-synthesis: none`、`-webkit-text-size-adjust: 100%`；`.card` 去掉 `backdrop-blur` 改用实色 `bg-surface`（消除发虚）；`.grad-text`/`.btn-solid` 改用 accent 变量；`::selection` 用 accent 着色。
- 运行中的 ShipKit 本体保持 midnight 默认外观不变（`:root` 默认值与旧十六进制一致）。

### 2. SaaS 风格可选（含实时预览）
- `config.ts`：新增 `StyleId` 类型 + `STYLE_OPTIONS`（midnight/paper/aurora/emerald），`BuilderConfig` 加 `style` 字段，默认值 `midnight`。
- 新增 `lib/generator/themes.ts`：`PALETTES`（四套调色板 RGB 通道）、`themeVars()`、`isLight()`、`buildGlobalsCss(style)`（按风格注入 `:root` 调色板）。
- `pack.ts`：覆盖生成 `app/globals.css`（所选风格调色板）；浅色风格（paper）时去掉 `app/layout.tsx` 的 `className="dark"`。
- `components/Builder.tsx`：新增 "06 · Style" 段（带色板预览），并在根容器注入 `themeVars` 实现实时换肤预览；"07 · Deploy" 段重排。
- 验证：paper+cloudflare 生成物 `globals.css` 含 `color-scheme: light`、layout 无 `dark` class；midnight+vercel 保持 `color-scheme: dark` + `dark` class。

### 3. Cloudflare 部署
- `config.ts`：`DeployTarget` 加 `cloudflare`，`DEPLOY_OPTIONS` 加 Cloudflare（含 note）。
- `templates.ts`：README 增加 Cloudflare Pages 部署段（@cloudflare/next-on-pages + wrangler）与 `buildWranglerToml()`；"What's in this build" 表加 Style 行。
- `route.ts` zod：deploy 枚举加 `cloudflare`，并加 `style` 枚举。

## 管理后台 + 模板：付费查看 / 订单 / 付款开关（2026-11-06）

用户诉求：ShipKit 站与模板都要「付费查看、订单」，适配各种付款方式；付款默认 creem、后续可切 waffo。

- 新增后台页 `/admin/orders`（provider-agnostic 订单流水）与 `/admin/access`（付费查看聚合：付费邮箱用户/已签发授权/订阅记录/最近授权明细）。
- 新增支付商无关订单数据层：`lib/orders.ts` + `supabase/migrations/0005_orders.sql`（`provider+provider_order_id` 幂等 upsert；Supabase 不可用时回退 `.data/orders.json`）；webhook 落地后 `recordOrder()`，金额/币种经 `NormalizedSubEvent.amount/currency` + `toMajor()` 归一（JPY/KRW 零小数自动处理）。四适配器（stripe/creem/paypal/waffo）均填充金额。
- 新增可运行付费墙样例页 `/premium`（站 + 模板共用）：服务端 `checkEntitlement` 判定，放行渲染付费内容、否则 CTA 指向 /pricing；内联提示样式**不依赖** `components/console/ConsoleUI`，故两套后台被剪枝时仍可独立存活。四语文案 `premium.*` 在 `lib/i18n-core.ts`。
